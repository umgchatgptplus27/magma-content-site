### 독자 범위와 경계

- 중심 장면은 평일 출근 전, 보유 코트 또는 구매 후보를 셔츠·니트·팬츠·신발과 함께 비교하려는 3040 남성의 일반적 준비 상황이다. 직종, 회사 문화, 이동 방식, 날씨, 실내 온도, 개인 체감과 코트의 제품 사양은 독자마다 다르다.
- 울·울 혼방·기타 혼방의 성능과 관리 범위는 섬유 비율, 직조·가공, 안감·심지·부자재, 제품 구조, 제조사 안내와 사용 조건에 따라 달라질 수 있다. 소재명, 외관, 손으로 만진 느낌만으로 보온·통기·방풍·발수·구김·내구성·세탁 가능 여부를 확정하지 않는다.
- 촉감은 개인의 피부 상태, 이너, 마찰, 착용 시간과 선호에 따라 다를 수 있다. 특정 표면감이 고급스러움·젊음·직장 신뢰·편안함을 보장한다고 쓰지 않는다.
- 출근 장소의 복장 기대, 대중교통·도보·차량 이동, 건물 출입·보관, 당일 기상은 날짜·장소·업무와 개인 조건에 따라 달라진다. 현재 안내를 확인할 항목으로만 둔다.
- 새 구매가 기본 해법은 아니다. 보유 코트의 라벨·상태·수선 이력 확인, 이너 한 겹 조절, 다른 코트·이동 계획 선택, 제조사·수선 전문가 문의, 착용 또는 구매 보류를 동등한 선택지로 둔다.

## 2. 핵심 구성 선정 기준

**권고안:** C를 채택한다. 울·혼방의 구성, 안감, 케어라벨, 촉감, 레이어, 신발·가방의 구체 사례는 Oliver가 원문 근거와 예외를 확인한 뒤 다섯 판단 책임 안의 조건부 사례로만 다룬다.

### 선정 원칙

1. **판단 책임 분리:** 다섯 섹션은 출근 장면, 제품 표기, 울·혼방 사양 비교, 촉감·레이어, 이동·다음 행동 중 하나의 책임만 맡는다.
2. **라벨·제조사 안내 우선:** 소재명·판매 문구·후기보다 섬유 구성, 안감·부자재, 케어라벨과 제조사 안내를 먼저 확인한다.
3. **조건부 언어:** ‘확인한다·대조한다·걸쳐 본다·한 요소만 바꾼다·문의한다·보류한다’로 쓴다. 소재 성능·관리·촉감 결과는 원문 근거와 적용 범위가 있을 때만 다룬다.
4. **한 번에 한 변수만 바꾼다:** 같은 이너·팬츠·신발을 기준으로 코트 한 벌, 이너 한 겹 또는 여밈 한 요소만 바꿔 본다.
5. **소재와 장면을 분리한다:** 섹션 1은 오늘의 장소·일정, 2는 라벨·구성, 3은 사양 대조, 4는 개인 촉감과 동작, 5는 이동·전신·다음 행동만 책임진다.
6. **보유품 우선:** 새 제품·브랜드·가격보다 보유 코트의 라벨, 현재 상태, 수선·세탁 이력, 이너·일정과의 연결을 먼저 본다.
7. **외모 불안과 성능 비약 방지:** 특정 소재·무게·표면감·기장이 더 젊어 보이게 하거나, 고급스럽고, 모든 출근길에 편안하거나, 날씨를 해결한다고 쓰지 않는다.
8. **불확실성은 보류:** 라벨·제조사 안내·장소 규정·기상·이동 정보가 없거나 서로 충돌하면 단일 코트를 정답으로 제시하지 않고 추가 확인·다른 조합·보류를 남긴다.
9. **모바일 독해성:** 각 섹션은 ‘무엇을 먼저 볼지 → 무엇을 한 가지 비교할지 → 언제 바꾸거나 멈출지’의 짧은 흐름으로 읽혀야 한다.
10. **MAGMA 적합성과 비주얼 구분성:** 다섯 섹션은 일정 확인, 라벨 확인, 두 코트의 사양 대조, 이너 위 촉감·동작 확인, 현관의 전신·가방 점검이라는 서로 다른 장면을 갖는다.

## 3. 핵심 방향 5개

> 아래 출근 규정·섬유 구성·가공·관리·촉감·피팅·기상·이동 관련 내용은 모두 **기획 후보**다. Oliver가 원문 근거·적용 범위·예외를 확인한 뒤 Noah가 유지·수정·삭제한다.

### 1) 코트보다 먼저 오늘의 출근 장면을 적는다 — 출근 장면과 우선 조건

- 역할: ‘울 코트가 필요한 날’이라는 전제보다 오늘의 사무실·외부 미팅·이동·보관·실내외 전환과 회사·방문처 안내를 먼저 분리한다.
- 확인 후보: 첫 일정과 장소, 회사·방문처의 복장·출입·외투 보관 안내, 출발·도착 시각, 이동 수단과 대기 구간, 당일 기상 정보를 확인할 공식 경로, 코트를 벗거나 들 상황.
- 판단 순서 후보: 일정 확인 → 장소·안내 확인 → 이동·기상 정보 대조 → 기본 이너·팬츠 선택 → 코트 사양 비교로 이동.
- 조절 방식 후보: 안내 재확인, 방문처에 중립적으로 문의, 이너·코트·이동 방식 조정, 다른 조합 준비, 보류.
- 피할 것: 모든 출근일·업종·미팅에서 코트가 같은 격식·보온·편의 결과를 내거나 특정 소재가 필수라는 일반화.
- 검증 필요: 직장·방문처별 복장·보관 안내의 변동성, 공공 기상 정보의 시간대·지역별 확인 범위, 이동 안내의 현재성.

### 2) 소재명보다 라벨과 제품 구성을 먼저 읽는다 — 라벨과 제품 구성

- 역할: ‘울’ 또는 ‘혼방’이라는 전면 소재명으로 결론 내리지 않고 섬유 구성, 안감·부자재, 케어라벨, 제조사 관리 안내와 현재 상태를 분리해 읽는다.
- 확인 후보: 섬유 구성·혼방 비율, 안감·심지·접착 부자재의 표시 여부, 세탁·표백·건조·다림질 관련 케어 기호, 제조사 관리·보관 안내, 오염·마모·이염·기존 세탁·수선 이력.
- 판단 순서 후보: 라벨·제조사 안내 확인 → 구성·부자재·현재 상태 기록 → 오늘의 이너·이동·보관 조건과 대조 → 착용·관리·문의·다른 코트 선택.
- 조절 방식 후보: 제조사·판매처·수선·전문 세탁 문의, 옷걸이·보관 계획 확인, 다른 코트 선택, 처리·구매 보류.
- 피할 것: 혼방 비율 하나, 손감 하나, 특정 케어 기호 하나만으로 모든 관리법·착용감·내구성을 정하는 표현.
- 검증 필요: GINETEX 등 관리 기호 원문, 제조사 케어 안내, 섬유 구성·안감·부자재와 관리 조건의 관계를 설명하는 원문.

### 3) 울과 혼방은 사양표 위에서 비교한다 — 울·혼방 사양 비교

- 역할: 울과 혼방을 좋은 것·나쁜 것으로 줄 세우지 않고, 동일한 출근 조건에서 후보 제품의 실제 표기와 확인 불가 항목을 나란히 둔다.
- 확인 후보: 섬유 비율과 원문 표기, 직조·가공·안감·부자재 정보, 제조사 관리 안내, 제품별 중량·두께·기능 표기 유무와 시험 조건, 누락된 정보.
- 판단 순서 후보: 비교 기준 고정(오늘의 이너·장소·관리 가능 범위) → 후보의 라벨·사양 대조 → 출처가 있는 사실과 개인 선호 분리 → 추가 확인·다른 후보·보류 결정.
- 조절 방식 후보: 동일 모델의 상세 사양 확인, 제조사 문의, 다른 코트 후보 대조, 구매·착용 보류.
- 피할 것: 울 함량, 혼방 여부, 두께, 가격만으로 보온·통기·방풍·구김·수명·격식을 일반화하는 표현.
- 검증 필요: 섬유 기관·표준·제조사 원문이 설명하는 섬유 표기와 제품별 성능 시험·관리 범위, 일반화의 한계.

### 4) 촉감은 이너와 움직임을 함께 두고 확인한다 — 촉감·레이어와 움직임

- 역할: 매장이나 거울 앞의 한 번의 손감만으로 결론 내리지 않고, 오늘 입을 이너와 함께 목·손목·어깨·소매·여밈의 접촉과 동작을 조건부로 관찰한다.
- 관찰 후보: 맨손과 이너 위에서의 표면감 차이, 목·손목 등 접촉 부위, 어깨·소매·앞여밈의 여유, 서기·가볍게 앉기·팔 움직임 전후, 수선 이력과 제조사 사이즈·관리 안내.
- 비교 순서 후보: 같은 이너·팬츠·신발 고정 → 코트 한 벌씩 걸쳐 보기 → 서기·팔 움직임·앉기 확인 → 이너 또는 여밈 한 요소만 바꾸기 → 기록·수선 문의·다른 코트·보류 판단.
- 조절 방식 후보: 이너 한 겹 변경, 여밈 조정, 다른 코트·사이즈 비교, 수선·판매처 문의, 보류.
- 피할 것: 부드럽거나 무거운 촉감, 짧은 피팅, 특정 핏이 장시간 편안함·피부 반응·체형 보정·고급스러움·직장 신뢰를 보장한다는 표현.
- 검증 필요: 제조사·테일러의 피팅·사이즈·수선 안내, 피부·마찰·알레르기와 의류 접촉을 다루는 신뢰 자료의 적용 범위, 짧은 착용 시험의 한계.

### 5) 이동과 도착 뒤까지 본 뒤 다음 행동을 정한다 — 이동·도착 전 다음 행동

- 역할: 소재·라벨·촉감 판단을 전신의 정돈감과 이동·도착·외투 보관의 실제 행동으로 연결하고, ‘입는다’ 외의 선택을 결론으로 남긴다.
- 관찰 후보: 코트를 걸친 전신과 벗은 기본 조합, 상·하의·신발·가방의 명도·표면·로고 집중도, 이동 수단·출입·보관 안내, 들고 벗을 가능성, 바꾼 한 요소와 아직 불확실한 정보.
- 판단 순서 후보: 섹션 1~4 요약 → 전신과 벗은 상태 확인 → 신발·가방·소품 한 요소 점검 → 이동·보관 안내 재확인 → 유지·교체·문의·보류 결정.
- 조절 방식 후보: 소품 최소화, 이너·신발·코트 한 요소 교체, 다른 조합, 방문처·제조사·수선 문의, 보류.
- 피할 것: 특정 신발·가방·소재·무로고 상태가 모든 출근길에서 안전·편안함·전문성·사회적 평가를 보장한다는 표현.
- 검증 필요: 교통·시설·방문처의 현재 안내, 제품별 보관·관리 범위, 남성복 편집 자료의 조건부 스타일링 언어와 이해관계.

## 4. 목차와 집필 구조

### 핵심 섹션 1 — 코트보다 먼저 오늘의 출근 장면을 적는다

  2. 회사·방문처의 안내와 현재 이동 조건이 일반적인 소재 조언보다 우선하는 이유는 무엇인가?
  3. 일정·드레스코드·기상·출입 정보가 불명확할 때 무엇을 문의·대조·보류해야 하는가?
- 산출 형식: 일정 확인 → 장소·안내 확인 → 이동·기상 정보 대조 → 기본 이너·팬츠 선택 → 사양 비교·다른 조합·보류.

  2. 소재명이나 손감 하나만으로 관리법·성능·착용 결과를 단정하면 안 되는 이유는 무엇인가?
  3. 현재 상태와 기존 처리 이력이 있을 때 언제 착용·관리·문의·다른 코트 선택으로 나눌 것인가?
- 산출 형식: 라벨·안내 확인 → 구성·상태 기록 → 이너·이동·보관 조건 대조 → 착용·관리·문의·보류.

### 핵심 섹션 3 — 울과 혼방은 사양표 위에서 비교한다

- 반드시 답할 질문
  1. 울·혼방 후보를 같은 출근 조건에서 비교하려면 어떤 제품 정보와 누락 정보를 나란히 둘 것인가?
  2. 섬유 비율·직조·가공·안감·제품별 안내를 성능의 보장으로 오해하지 않으려면 어떤 근거와 한계가 필요한가?
  3. 정보가 부족하거나 서로 다른 시험·표기가 섞일 때 무엇을 추가 확인하거나 보류할 것인가?
- 산출 형식: 비교 조건 고정 → 라벨·사양 대조 → 확인된 사실/개인 선호 분리 → 추가 확인·다른 후보·보류.

### 핵심 섹션 4 — 촉감은 이너와 움직임을 함께 두고 확인한다

- 반드시 답할 질문
  1. 같은 이너·팬츠 위에서 목·손목·어깨·소매·여밈의 접촉과 여유를 어떤 순서로 관찰할 수 있는가?
  2. 서 있을 때와 앉거나 팔을 움직일 때 무엇을 따로 확인해야 하는가?
  3. 이너·여밈·코트·수선 문의 중 언제 무엇을 한 가지 바꾸거나 보류할 것인가?
- 산출 형식: 같은 이너·팬츠 고정 → 코트 걸쳐 보기 → 서기·동작·앉기 확인 → 한 요소만 변경 → 기록·문의·다른 코트·보류.

### 핵심 섹션 5 — 이동과 도착 뒤까지 본 뒤 다음 행동을 정한다

- 반드시 답할 질문
  1. 코트를 걸친 상태와 벗은 상태, 신발·가방·소품을 왜 함께 확인해야 하는가?
  2. 출입·보관·이동 조건이 불명확할 때 무엇을 정답으로 만들지 말고 어디에 문의할 것인가?
  3. 그대로 착용·조합 변경·제조사 또는 수선 문의·다른 코트 선택·보류 중 오늘의 다음 행동을 어떻게 정할 것인가?
- 산출 형식: 1~4 판단 요약 → 전신·벗은 상태 점검 → 신발·가방·소품 한 요소 조정 → 안내 재확인 → 유지·교체·문의·보류.
