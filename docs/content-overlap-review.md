# 반복 콘텐츠 검토 및 2차 개선

## 범위와 한계

- 공개 글 218개 본문을 전수 비교했다. 출처 목록·이미지·URL을 제외한 단어 내부 3글자 TF-IDF 코사인 유사도이며, 문서 절반 이상에 등장한 공통 3글자는 제외한다.
- 결과: `content-overlap-audit.json`. 전체 글마다 가장 가까운 다른 글을 기록하고 상위 50쌍을 추렸다. 재실행: `node scripts/content-overlap-audit.mjs`.
- 이는 검토 순서를 정하는 도구다. 독창성 점수나 Google 승인 기준이 아니고, 낮은 유사도가 좋은 글을 뜻하지 않는다.
- 아래 5쌍은 본문을 직접 대조했다. 218개 전체의 사실·사진·독창성을 정독 검수한 결과라고 주장하지 않는다.
- 이번에는 삭제·리디렉션·canonical 변경을 하지 않는다. 기존 URL의 검색 유입·백링크 자료 없이 대표 URL을 정하지 않는다.

## 본문 대조 결과

### 1. 카페 작업 / 도서관 독서 모임 — 공통 가이드로 통합할 후보

- `content/posts/mens-autumn-cafe-work-outfit-guide.md`: 18행부터 장소·좌석, 34행부터 이동 날씨, 50행부터 앉는 핏, 66행부터 레이어와 소지품, 82행부터 귀가와 관리.
- `content/posts/mens-autumn-library-reading-outfit-guide.md`: 16행부터 이용 조건, 28행부터 복장 정보량, 40행부터 착석, 52행부터 날씨, 64행부터 소지품과 관리.
- 장소 이름을 빼면 독자의 행동 순서가 상당 부분 겹친다. 카페 글이 서울도서관 디지털자료실을 출처로 드는 점도 카페 고유 정보와 자료의 범위가 어긋나는지 검토할 이유다. 도서관법의 시설 정의 역시 옷 고르기의 답을 직접 제공하지 않는다.
- 제안: '오래 앉는 날의 옷과 가방 점검' 공통 가이드 안에 노트북 작업 / 독서 모임 분기를 둔다. 공통 착석·레이어·주머니 설명은 한 번만 쓰고, 기기·책·좌석의 차이와 실제 사용 기록을 각 분기에 남긴다.
- 통합 실행 조건: Search Console의 두 URL 유입과 질의, 기존 링크를 비교해 대표 URL을 정하고, 다른 URL의 고유 내용과 출처를 옮긴 뒤 영구 리디렉션·사이트맵·내부 링크를 함께 검증한다. 현재는 후보 확정까지이며 통합 배포는 하지 않았다.

### 2. 첫 입주자 모임 / 가족 모임 — 별도 유지, 일반론 반복 축약

- `mens-first-residents-meeting-outfit-guide.md:14,32,48,64,80`: 모임 안내 → 조합 → 착석 → 날씨 → 소지품의 공통 틀.
- `mens-family-gathering-outfit-guide.md:17,29,41,53,65`: 실제 동선과 상의·하의 교체, 돌봄 등 가족 활동, 조명에 따른 비교가 있다.
- 만나는 대상과 행동이 다르므로 '모임'이라는 단어만으로 합치지 않는다. 입주자 글은 모임 고유 정보가 부족해 보강 우선이며, 가족 글로 무조건 보내면 기대한 답이 달라진다.
- 제안: 입주자 글은 실제 안내문에서 확인한 활동 유형·실내외 여부와 차림 비교가 확보될 때 보강한다. 가족 글은 상의 교체·착석·돌봄 동작을 실제 기록으로 대체한다. 반복되는 날씨·라벨 설명은 짧은 안내나 관련 글 링크로 줄인다.

### 3. 장거리 운전 / 장시간 비행 — 통합하지 않음

- `mens-long-drive-outfit-guide.md:57,71`: 제어장치 간섭, 안전한 정차 후 관찰이 핵심이다.
- `mens-long-flight-outfit-guide.md:65,83`: 보안검색·수납·도착 후 전환이 핵심이다.
- 착석·레이어라는 공통 단어가 있어도 사용 환경과 안전 조건이 다르다. 합치면 맥락이 사라진다.
- 제안: 공통 핏 설명만 줄이고 운전 중 관찰 금지, 항공사·공항별 조건은 보존한다. 실제 착용 데이터가 생겨도 안전성이나 건강 효과를 시험했다고 표현하지 않는다.

### 4. 재킷 칼라 들뜸 / 소매 비틀림 — 통합하지 않음

- `mens-jacket-collar-gap-fit-guide.md:11,19,57`: 갭과 롤, 목·윗등의 관찰.
- `mens-jacket-sleeve-pitch-fit-guide.md:11,17,57`: 소매 각도·봉제선·암홀의 관찰.
- 높은 본문 유사도는 같은 착장 설명과 사진 조건·수선 전 확인 절차에서 발생하지만 실제 문제는 다르다.
- 제안: 관찰 조건과 거래 증빙 안내를 공통 페이지 또는 간결한 공통 문단으로 줄이고, 각 글에는 해당 부위를 보여 주는 직접 촬영 자료와 관찰 결과를 남긴다. 생성 이미지로 미세한 핏 결함을 입증하지 않는다.
- 추가 발견: 칼라 글 27행과 소매 글 25행의 'Oliver의 조사'는 독자가 확인하기 어려운 조사 주체다. 제작 담당자 이름이라면 제거하고 정확히 연결되는 출처·범위를 확인해야 한다. 이번 모바일 수정 범위에서 사실 근거 없이 다른 출처로 치환하지 않았다.

### 5. 데님 셔츠 출근 / 트렌치코트 출근 — 품목별 차별화 재작성, 단순 병합 비추천

- `mens-denim-shirt-commute-guide.md:14,40,66`과 `mens-trench-coat-commute-guide.md:14,38,50`: 일정·레이어·신발·가방 순서와 표현이 반복된다.
- 다만 셔츠와 코트는 확인할 부위와 제품 기능이 달라 유지할 이유가 있다. 데님 글 28행 이후의 데님/샴브레이 구분과 셔츠 밑단, 트렌치 글 26행 이후의 코트 기장·벨트·겹침 같은 품목 고유 질문을 중심으로 다시 구성한다.
- 대학 체육시설 정책, 일반 통근과 직접 관계없는 특정 운송약관 등을 늘리는 대신 실제 보유품의 착용·휴대 사진과 비교를 제공한다. 원문을 더 많이 붙이는 것 자체가 차별화는 아니다.

## 이번에 실제 반영할 범위

- 표를 독립된 가로 스크롤 영역으로 감싸 320px 화면에서 문서 전체가 벌어지는 문제를 수정.
- 티셔츠·출근 셋업 대표 글에 빈 CSV 관찰 기록표와 사용 방법 제공.
- 양식을 측정 사례로 부르지 않으며, 실물 자료 수집 기준은 `field-evidence-kit.md`에 별도 기록.

## 재심사 전 남은 관문

- 실제 촬영·관찰 자료 수령과 대표 글 사례 편집.
- 통합 후보의 유입·질의·링크 확인 및 대표 URL 결정 후 내용 통합. 대량 삭제나 일괄 noindex로 대체하지 않음.
- 비슷한 틀로 자동 생성되는 원고가 계속 공개되지 않도록 발행 운영 정책 별도 확인. 이번 작업은 자동 발행 스케줄을 중지하지 않음.
- 제작 흔적 검사를 통과한 글도 조사 주체·출처의 직접 관련성·실제 사례를 추가로 검토할 필요가 있음.
- 기술 검증 통과와 콘텐츠 가치 판단은 별개. 재심사 요청·색인 요청은 하지 않음.
