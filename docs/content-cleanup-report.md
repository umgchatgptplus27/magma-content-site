## 검증 명령

```sh
npm run test:editorial
npm run lint
npm run build
node scripts/content-editorial-audit.mjs
python3 scripts/verify-editorial-site.py http://127.0.0.1:3389 /tmp/magma-editorial-local-verification.json
```

로컬 발행 API 테스트는 전용 테스트 키를 사용하는 별도 dev 서버에서 실행한다. `EDITORIAL_QA_BASE_URL`과 `EDITORIAL_QA_KEY`를 지정하여 `node --test scripts/publish-quality-api.test.mjs`를 실행한다. 기존 slug만 사용해 422/409를 검증하며 새 글을 만들지 않는다. 운영에서는 실행하지 않는다.

로컬 프로덕션 빌드의 공개 글 218개 HTTP 200·제목·canonical·제작 흔적 검사를 통과했다. 10개 목록 페이지에서 중복·누락 없이 218개 글이 연결되고 사이트맵에도 모두 있다. 이는 HTTP/마크업 검사이며 실제 색인이나 AdSense 승인을 뜻하지 않는다.

## 감사 파일 읽는 법

- `content-cleanup-audit.json`: 원고별 변경 여부, 기계 검출 결과, 제거한 이미지 수, 출처 보존, 제목 유사 후보.
- `content-cleanup-audit.csv`: 사람이 편집 대상을 정렬해 검토할 목록.
- 분류는 **휴리스틱**이다. 기계 검사 통과를 품질 승인으로 해석하지 않는다.
- 제목 2-gram Jaccard ≥ 0.5는 제목이 비슷한 후보만 찾는다. 모자/폴로처럼 실제 주제가 다른 오탐도 있으므로 해당 결과만으로 통합하지 않는다.

## 남은 편집 작업

1. 반복된 상황별 옷차림 글의 실제 답과 검색 의도를 대조한다. 같은 결론이라면 대표 글에 정보를 합치고, 기존 유입과 링크를 확인한 뒤 URL 처리 방식을 결정한다.
2. 자료 요약을 넘어서는 실물 사진·측정·착용·관리 사례는 아직 확보하지 않았다. 운영자가 제공한 진짜 자료를 바탕으로 대표 글을 보강한다.
3. 운영자의 실제 배경이나 전문 경력은 제공되지 않아 임의로 넣지 않았다.
4. 생성 이미지 전체를 실물 정확성 기준으로 수동 검수한 것은 아니다. 문제가 확인된 참조만 제거했으며 나머지는 예시로 안내한다.
5. 기계 게이트는 독창성, 사실 정확성, 저작권, AdSense 승인 여부를 평가하지 않는다. 자동 발행 스케줄 자체도 중지하지 않았다.
6. 재심사 요청은 위 정비의 공개 반영과 추가 대표 콘텐츠 보강을 사람이 검토한 뒤 별도로 결정한다.
