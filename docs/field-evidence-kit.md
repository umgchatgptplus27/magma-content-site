# 대표 글 실물 자료 수집 양식

상태: 실제 사진·실측 결과 미수령. 빈 기록 양식은 실측 사례나 독창성 입증 자료가 아니다. 공개 글에 가상의 측정값, 타인의 체험, 생성 이미지를 실물 증거로 넣지 않는다.

## 티셔츠 목선 글

- 이미 가진 티셔츠 한 벌이면 된다. 사례를 만들기 위해 일부러 뜨거운 물·강한 열·약품을 쓰거나 옷을 손상시키지 않는다.
- 전체 앞면, 목선 근접, 관리라벨 원본을 촬영한다. 개인 정보가 찍히지 않도록 하고 본인이 촬영했거나 공개 권한이 있는 파일만 제공한다.
- 마른 옷을 앞면이 위로 오도록 평평하게 놓고 당기지 않는다. 목 입구의 좌우 끝 사이 직선 거리를 잰다. 목둘레 치수가 아니며 정상/불량의 합격선이 아니다.
- 줄자의 시작점과 끝점을 한 화면에 담는다. 옷을 다시 놓고 같은 점에서 한 번 더 재서 원자료를 모두 적는다. 서로 다르면 그 차이를 숨기지 않는다.
- 이전 측정이 없다면 현재 상태 기록으로만 쓴다. 다음 일상 관리 뒤 비교하려면 라벨이 허용하는 평소 관리만 하고 완전히 마른 상태에서 같은 방식으로 기록한다.
- 관찰 일시, 실제 한 관리, 사진 파일명, 측정값, 측정 위치, 관찰 중 달라진 조건을 `public/downloads/tshirt-observation.csv`에 적는다.
- 전달할 최소 자료: 현재 사진 원본과 현재 관찰 기록. 전후 비교를 주장하려면 양쪽 원본과 관리 기록이 모두 필요하다.

## 출근 셋업 글

- 같은 재킷·팬츠·신발에 이너만 바꾼 조합처럼 한 요소를 바꾼 두 구성을 비교한다. 새 제품을 살 필요는 없다.
- 같은 자리에서 앞·옆 모습을 찍고, 단추 잠금·책상 자세·앉기·일어나 걷기를 직접 확인한다. 통증이나 움직임 제한이 생기면 중단한다.
- 각 조합의 옷 식별명, 사이즈, 사진 파일명, 관찰 시간, 실제 불편과 선호를 `public/downloads/office-outfit-comparison.csv`에 적는다.
- 얼굴은 나오지 않아도 된다. 몸 치수나 신원을 공개할 필요가 없다. 체형 일반화 대신 이 착용자·이 옷·이 조건에서의 관찰로 제한한다.
- 잠깐 입어 본 결과를 장시간 착용 후기나 보온·내구 성능 평가로 바꾸지 않는다.

## 자료 수령 뒤 편집 기준

1. 사진과 기록의 제품·날짜·조건이 서로 일치하는지 확인한다.
2. 사진 공개 권한과 개인정보 노출을 확인한다.
3. 표의 각 관찰에 원본 파일명을 연결한다.
4. 직접 관찰 / 공식 자료의 설명 / 편집자의 해석을 구분한다.
5. 실제 사례가 없는 칸은 비워 두고 수치를 채우지 않는다.
6. 게시용 원고와 사진을 사용자에게 보여 준 뒤 공개 승인 범위를 확인한다.

실물 자료가 없으면 이 단계를 완료했다고 표시하지 않으며, 양식 추가만으로 애드센스 재심사 준비 완료를 선언하지 않는다.
