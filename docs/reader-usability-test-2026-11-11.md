# 실제 독자 사용성 테스트

상태: 참가자 응답·실행 결과 대기. 브라우저 에이전트 점검을 사람의 평가로 기록하지 않는다. 사이트에 익숙하지 않은 독자가 직접 수행하며, 도중에 메뉴 위치나 정답을 알려주지 않는다. 이름·신체 치수 등 개인정보는 기록하지 않아도 된다. 이 문서는 운영용이며 사이트 글로 발행하지 않는다.

시작 주소: https://www.eurachoachoa.com/

| 과제 | 참가자에게 읽어 줄 말 | 진행자가 확인할 점 |
| --- | --- | --- |
| 1. 정보 찾기 | 온라인 셔츠 구매 전에 가진 옷과 어떻게 비교할지 찾아보세요. | 첫 경로, 되돌아감, 측정 위치 구분 여부 |
| 2. 계산 이해 | 가상의 두 옷은 같은 위치에서 쟀습니다. 가진 옷의 가슴단면 54cm·소매 61cm, 후보는 56cm·60cm입니다. 비교하고 결과의 뜻을 설명해 주세요. | 단면 +2cm·소매 -1cm 이해, 착용감 자동 판정으로 오인하는지 |
| 3. 관리 판단 | 니트에서 둥근 보풀과 길게 빠진 실을 발견했습니다. 각각 어떻게 할지 찾아 설명해 주세요. | 보풀과 올 뜯김 구분, 제거를 멈출 조건 |
| 4. 라벨 해석 | 손세탁 표시가 있는 옷을 세탁기 손세탁 코스에 넣어도 되는지 찾아보세요. | 손세탁 기호와 기계 코스의 차이 이해 |

각 과제의 시작·종료 시간, 실제 경로, 막힌 지점, 도움 요청, 독자 자신의 설명을 기록한다. 성공 여부를 먼저 유도하지 않는다. 도움을 줬다면 도움 없는 성공으로 세지 않는다. 종료 후 “가장 불편했던 부분”, “다른 사이트보다 도움이 된 부분”, “설명이 부족한 부분”을 묻는다.

기록표: `reader-usability-results-2026-11-11.csv`. 실제 수행 전에는 결과 행을 채우지 않는다. 소수 참가자의 결과를 전체 독자의 선호나 승인 확률로 일반화하지 않는다. 관찰된 반복 문제부터 고치고 해당 과제만 다시 확인한다.
